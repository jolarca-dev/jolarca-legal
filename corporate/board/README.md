# board/ — Minutes and resolutions

One folder per meeting, numbered sequentially across years:
`YYYY-NN-short-title/`.

Each meeting folder contains:

- `minutes.md` — attendees, quorum note, agenda, decisions summary
- `resolution-NN-<subject>.md` — one file per resolution, each stating:
  - the resolution text (adopted verbatim),
  - the authority relied on (articles clause / PoA),
  - voting outcome,
  - signing requirement and who signed.

Rules:

- Minutes are approved at the next meeting; the approval is recorded in
  that next meeting's minutes. Approved minutes are immutable.
- Written resolutions follow the same numbering with the meeting slot
  marked `written-procedure`.
- No personal data beyond director names/titles; remuneration detail
  stays in the sealed HR custody location.
