# formation/ — UAB incorporation records

Lithuanian private limited liability company (UAB) formation file.

Contents (filed records; corrections are new filings, never rewrites):

- Articles of association (current version + prior versions)
- Incorporation deed and founding resolution
- JAR (Register of Legal Entities) extracts — dated, one file per pull
- Share capital payment evidence pointer (custody: bank statement in DMS)
- Any amendments: one subfolder per amendment with the notarial reference

Naming: `YYYY-MM-DD-<subject>[-<authority-ref>].md|.pdf`.
