# pre-litigation/ — Demand letters & escalations

- **Demand letters out:** drafts and dispatched versions, with dispatch
  proof; each letter gets the matter id it seeds.
- **Demand letters in:** same-day intake; counsel routing per
  `../README.md`; do not respond without counsel.
- **Takedown escalations:** IP takedowns (marketplace listings, domains)
  that exceed routine moderation — links to
  `intellectual-property/` watch notes.
- **Seller disputes escalated:** suspension/termination appeals that
  threaten legal action — DSA Art. 20/21 track first, then matter.

Matters graduate to `active/` when proceedings start or counsel decides
litigation posture; until then they stay here with the same folder
convention.
