# partnerships/ — Channel & referral partners

Dioceses, funeral-home networks, artisan guilds, and other referral/channel
partners.

Convention mirrors `vendors/`: one folder per partner, `metadata.md` +
dated instruments, `_register.csv` (same schema) when the first instrument
executes.

Watch items:

- Referral economics (commission, rev-share) are High-risk: GC + finance
  alignment recorded in `metadata.md` before signature.
- Use `00-templates/partnership-referral.md` as preferred paper; IP
  positions CL-40/CL-41 apply to co-created content.
- Partners handling buyer/seller personal data need a DPA in place before
  go-live (link the jol-m-compliance vendor assessment).
