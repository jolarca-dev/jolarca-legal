# customers/ — Enterprise & institutional agreements

Institutional customers: dioceses, chains of funeral homes, municipalities.

Convention mirrors `vendors/`: one folder per customer, `metadata.md` +
dated instruments, and a `_register.csv` (same schema as vendors) created
when the first instrument executes.

Watch items specific to this segment:

- Institutional church bodies may require processor-role DPAs
  (`00-templates/dpa-processor.md`) — rare; confirm roles before drafting.
- Multi-year service commitments need the value-tier check in
  `docs/signing-authority-matrix.md` before signature.
- Sacred-goods sensitivities: listing/content obligations in customer
  contracts must align with `legal-texts/community-standards/`.
