## Mandatory content checklist (Art. 33 DK minimum)

- [ ] Parties (employer details from `corporate/formation/`)
- [ ] Job function / position description
- [ ] Place of work (incl. remote-work terms if applicable)
- [ ] Start date (and probation, ≤ 3 months)
- [ ] Remuneration (gross, incl. components) — in the contract per DK
- [ ] Working time arrangement
- [ ] Annual leave entitlement
- [ ] Notice periods per DK

## Deal-sheet defaults

| Parameter | Default | Concession limit |
|-----------|---------|------------------|
| Probation | 3 months | DK maximum |
| IP | assignment of work product (CL-40) | no-concede |
| Confidentiality | during + 2 years post | trade secrets indefinite |
| Non-compete | only with compensation per DK Art. 40; GC case-by-case | not standard for all roles |
| Remote work | cost compensation per DK | |

## Data minimization

Employee personal data (ID codes, bank details, health) belongs in the HR
custody location — NOT in this repository. Executed contracts file under
`contracts/employment/` with `metadata.md` pointers only.
