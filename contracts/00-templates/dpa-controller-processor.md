## Deal-sheet defaults

| Parameter | Default | Concession limit |
|-----------|---------|------------------|
| Form | JOL paper (this template) | counterparty DPA only w/ GC mapping review |
| SCCs | 2021/914, module per roles, per CL-21 | no pre-2021 SCCs |
| Sub-processors | prior specific or general + objection right (CL-22) | |
| Breach notice to JOL | ≤ 48 hours (CL-23) | 72h absolute floor |
| Audit rights | JOL audit/inspection annually + on incident | third-party report substitute acceptable |
| International transfers | only with valid mechanism + TIA reference | no-concede on bare transfers |

## Structure

1. Parties, roles, processing description (Annex I)
2. Instructions; purpose limitation
3. Confidentiality of processor personnel
4. Security measures (Annex II — tie to ISO 27001/SOC 2 evidence where held)
5. Sub-processors: list (Annex III), notification, objection mechanics
6. Data subject rights assistance (with cost allocation)
7. Breach notification & cooperation
8. Records; audit & inspection rights
9. International transfers: SCC module + TIA reference
10. Return/destruction at end of services (certified, CL-32)
11. Liability allocation consistent with CL-02 carve-outs
12. Annexes: I processing description, II TOMs, III sub-processors
