# imprint/ — Legal entity disclosures (e-commerce information duties)

Provider identification required for the marketplace storefront per
LT (Elektroninės komercijos įstatymas / Civil Code), LV (Patērētāju
tiesību aizsardzības likums info duties), and EE equivalents, plus
distance-selling information under CRD Art. 6.

Content (per market):

- Legal entity: UAB "Journey of Life", registration code, registered
  address, VAT code — values pulled from `corporate/formation/` and
  `corporate/registrations/` (update the same day any registration changes).
- Contact channels incl. fast direct-communication means.
- Supervisory authority references where activity is licensed/regulated.
- ODR platform link + national consumer-protection body contacts.
- VAT display rules (incl. OSS context pointer).

One file per market language; differences between markets are tracked as
versioned changes like any other text.
