# trade-secrets/ — Designation register

What we deliberately do **not** patent or disclose. Trade-secret
protection (EU Directive 2016/943 / LT implementation) requires that we
take reasonable steps to keep the information secret — this register is
part of those steps.

## Designation register

| ID | Subject | Designated | Custody | Access | Review |
|----|---------|-----------|---------|--------|--------|
| TS-001 | (example) seller-ranking implementation details | TBD | code repo | eng only | annual |
| TS-002 | (example) supplier/commission economics | TBD | finance + GC | GC + finance | annual |

## Handling rules

- Designated material is never committed to public repos, never pasted
  into issues; references by ID only.
- NDAs with contractors/partners must cover the register's subjects —
  the clause library (CL-02) keeps confidentiality carve-outs uncapped.
- Disclosures (even accidental) are logged here with remediation;
  material disclosures go through SECURITY.md.
- Annual review: each designation re-justified or released.
