Rules:

- Primary domains carry registry lock and 2FA'd registrar accounts;
  credentials in Vaultwarden, not here.
- Defensive registrations reviewed annually (renew or release with GC
  note — releases are logged here with the reason).
- Expiry > 6 months out is a non-event; expiry inside a quarter is an
  escalation (missed renewal of a primary domain is a P1).

## UDRP watch notes
