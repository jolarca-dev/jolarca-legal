# intellectual-property/ — IP strategy & portfolio

## Strategy

| Asset | Register? | Where | Why |
|-------|-----------|-------|-----|
| "Journey of Life" word mark | yes | EUIPO (classes 9/35/45) | core brand across software, marketplace services, funeral/ritual services |
| Logo | yes | EUIPO (fig mark, same classes) | visual identity |
| Domains | n/a (registration) | registrar portfolio | defensive + primary |
| Software copyright | no registration | AGPL-3.0 posture + CLA/DCO | open-source governance, see `copyright/` |
| Trade secrets | deliberately not disclosed | internal designation register | algorithms, supplier relationships |

## Structure

| Path | Contents |
|------|----------|
| `trademarks/` | EUIPO filings, class strategy, renewal calendar |
| `domains/` | Portfolio register, UDRP watch notes |
| `copyright/` | OSS posture, CLA, license compliance |
| `trade-secrets/` | Designation register (what we do NOT register/disclose) |

Renewal cadence: quarterly review via `ip-renewals.yml`. Any infringement
discovery is escalated per SECURITY.md (counsel first) and logged as a
matter in `disputes/pre-litigation/`.
