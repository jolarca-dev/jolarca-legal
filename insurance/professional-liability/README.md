# professional-liability/ — Errors & omissions

Covers wrongful-act claims arising from the services the marketplace and
organization provide (e.g., facilitated funeral service arrangements,
service-level failures toward institutional customers).

- Summary per policy period: limits, retention, claims-made vs
  occurrence, retroactive date.
- Contract tie-in: liability caps in customer/partner contracts
  (`contracts/_clause-library.md` CL-01/CL-02) must stay inside policy
  limits — GC checks this when caps are negotiated upward.
- Claims file under `../claims/`; disputes intake checks coverage per
  `../README.md` procedure.
