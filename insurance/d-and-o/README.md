# d-and-o/ — Directors & officers liability

Summary per policy period: insurer, limits, retention, covered-entity
scope (UAB + subsidiaries if any), side A/B/C structure.

Watch items:

- Capital raises, cap-table changes (`corporate/cap-table/`), and
  investor appointments are notification events under most D&O forms —
  check the policy conditions before closing such transactions.
- Board resolutions with material financial exposure get a D&O check
  note in the meeting folder.
- Run-off cover requirement tracked for any future transaction.
