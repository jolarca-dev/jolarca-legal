# Glossary — LT/LV/EE legal term equivalents

Translation consistency is legally load-bearing: the same concept must
carry the same term across languages and across texts. When a translation
lands in `legal-texts/`, any new term pair is added here in the same PR.

Rules:

- Additions require GC approval (a wrong equivalence is a legal defect).
- Deprecated terms stay listed with a "do not use" note — translations
  in circulation must remain interpretable.
