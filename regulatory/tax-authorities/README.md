# tax-authorities/ — VMI / VID / EMTA

- Rulings and binding positions requested by us (e.g., marketplace
  commission VAT treatment) file here with the question, ruling text,
  and the `platform-regulation/vat-oss/` memo it informs.
- Audit/investigation contact becomes an `../inquiries/` matter — from
  that moment counsel leads and this folder holds only non-privileged
  pointers.
- Routine declarations stay with finance; this repo stores positions and
  correspondence, not filing payloads with taxpayer data.

Convention: one folder per authority; ruling files
`YYYY-MM-DD-ruling-<subject>.md`; correspondence per the regulatory
README convention.
